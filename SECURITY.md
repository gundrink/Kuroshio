# Security policy

Kuroshio is a Solana devnet program. Do not use it with real funds.

## Reporting a vulnerability

Open a private security advisory on the source repository, or open an issue if the problem is already public:

https://github.com/gundrink/Kuroshio

Please include the program id `2Q7mJej5TW3y5Uadf68KPFKV1BnKrDAibQLDZXyZyPox`, the cluster, and a transaction that shows the problem. Do not include private keys.
