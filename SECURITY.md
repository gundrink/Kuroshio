# Security policy

Pool Ninja is a Solana devnet program. Do not use it with real funds.

## Reporting a vulnerability

Open a private security advisory on the source repository, or open an issue if the problem is already public:

https://github.com/gundrink/pool-ninja

Please include the program id `GRG9CqaYABVi2Z67CBFbkq9vHC8VJ2CtvCtmqs3woHqE`, the cluster, and a transaction that shows the problem. Do not include private keys.
